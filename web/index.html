将该单文件 HTML 发送到你或朋友的安卓手机上，使用 Chrome 或 Edge 浏览器打开，点击右上角菜单选择「添加到主屏幕」，即可获得独立桌面图标、无地址栏全屏体验，并支持直接调取手机后置摄像头与本地离线存储。

方式三：当前安装包已内置原生壳（推荐直接用）

这个 APK 用 WebView 加载上面的单文件网页，已接好相机/相册选图、系统步数、每日提醒、自动备份，不依赖 Capacitor 或 Gradle。换手机时在「设置」里导出备份，新机导入即可。
