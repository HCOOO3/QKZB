# 轻卡账本 v1.24.1

## 本次更新

- 营养素超标提示移动到「每餐热量占比」下方
- AI 识菜 / 文字补录返回钠估算
- 手动食物库扩到 340 条，新增外卖快餐 40 条
- 食物库支持拼音搜索、收藏、常用份量（½/1/2 个/盒/碗）
- 看板新增钠摄入与超标建议
- 自建食物支持填写钠
- 月度报告 CSV / PNG
- 桌面小组件 1x1 / 2x2 自适应
- 通知栏快捷：+250ml 水、记一餐

## 安装

下载 `轻卡账本-v1.24.1.apk`，Android 7.0+，覆盖安装不会丢数据。

## 注意

- 数据仅保存在本机，卸载前请先导出备份
- AI 功能需要自行配置 API Key
